# AI Backend Prompts - Distributed Systems Context

This repository provides context for evaluating AI-generated solutions for complex backend engineering problems.

## System Overview

The system simulates a distributed backend architecture for a large-scale application, including:

- High concurrency scenarios (e.g., stock reservation)
- Asynchronous processing with message queues
- Authentication and authorization using JWT
- Resilience patterns (retry, circuit breaker)
- High-throughput data processing

## Purpose

The goal is to evaluate AI models on their ability to:

- Design scalable architectures
- Handle concurrency and consistency
- Implement robust backend logic in Java
- Address real-world engineering trade-offs

Each prompt associated with this repository is independent and focuses on a specific backend challenge.
